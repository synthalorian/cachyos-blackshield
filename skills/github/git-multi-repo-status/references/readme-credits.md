# README Credit Template

Standard credit format for all synth/synthclaw projects.

## Standard Credit Section

```markdown
## Credits

Developed by **synth** ([synthalorian](https://github.com/synthalorian)) with assistance from **synthclaw** 🎹🦞 — a digital entity from the neon grid of 1984.
```

## Variations Used

### At bottom of README (no existing credits section):
Append before the last line or under the License section:

```markdown
---

## Credits

Developed by **synth** ([synthalorian](https://github.com/synthalorian)) with assistance from **synthclaw** 🎹🦞 — a digital entity from the neon grid of 1984.

*This is the wave. 🎹🦞🌆*
```

### Replace existing author line:
Simple credit line in existing "Credits" section:
```markdown
Developed by **synth** ([synthalorian](https://github.com/synthalorian)) with heavy lifting by **synthclaw** 🎹🦞 — a digital entity from the neon grid of 1984.
```

### Long-form with process description (used in open_habit):
```markdown
Created by [synth](https://github.com/synthalorian) with assistance from **synthclaw** — an AI collaboration partner that brings the code, the architecture, and the late-night debug sessions.
```

## GitHub Repo Description Format

```bash
gh repo edit synthalorian/repo-name --description "🎹🦞 Short description. Tech stack. Developed by synth with synthclaw."
```
