## Prompt Construction Tips

### Structure
1. **Era**: "80s", "1980s", "retro"
2. **Genre**: "synthwave", "darksynth", "outrun", "dreamwave"
3. **Instruments**: Specific synths, drums, bass
4. **Production**: "warm", "lo-fi", "analog"
5. **Atmosphere**: "neon", "night", "cinematic"
6. **Tempo**: "118 BPM", "driving beat"
7. **Reference artist**: Optional style guide

### Common Mistakes to Avoid
- Too vague: "electronic music" (too generic)
- Conflicting terms: "aggressive chillwave" (contradictory)
- Missing atmosphere: "synth track" (needs mood/vibe)
- Wrong tempo: "140 BPM dreamwave" (too fast for genre)

## Advanced Prompt Techniques

### Layering
Build complex prompts by layering elements:
```
80s synthwave + driving beat + gated reverb + 
analog bass + arpeggiated lead + neon atmosphere
```

### Specificity Scale
- **Broad**: "synthwave track"
- **Medium**: "80s synthwave driving music"
- **Specific**: "Kavinsky Nightcall style, 118 BPM, analog bass, gated reverb, night highway"

### Emotion Tags
Add emotional context:
- "melancholic beauty"
- "triumphant feeling"
- "mysterious mood"
- "hopeful longing"
- "bittersweet memory"
